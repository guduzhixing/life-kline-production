# 音频设计、制作与质检标准（v1.0）

适用范围：所有为用户生成的语音、播客、旁白类音频。未通过质检门禁的音频不得交付。

## 1. 脚本设计标准（生成前）
1. 单轮发言拆短：中文每轮建议 30-60 字，最多 80 字；超过 80 字必须拆分。长句是卡壳、重复和幻觉的高风险触发点。
2. 每轮必须是完整句：有主语和谓语，以句号、问号或感叹号收尾；禁止电报式碎句、标题式短语连排。
3. 语义无歧义：
   - 每句的代词（它、他、她、这、那、这样）必须能在同一轮或上一轮找到明确指代对象；轮次开头不得用无指代的代词。
   - 同一概念全程只用一个名称（例如统一用“外骨骼”，不得在同集混用未解释的近义词）。
   - 数量、时间、年份必须写成口语完整形式；首次出现的英文缩写必须先给出中文全称。
   - 一句只讲一个意思；并列条件超过两个时，拆成多句逐项说。
4. 禁止内容：舞台指示、括号说明、引用标记、链接原文、数学符号、视觉化分隔符、未解释的行话。
5. 防重复设计：稿内不得出现两段意思和措辞高度相同的段落；过渡句、总结句不得与正文逐字重复。
6. 事实口径：时间敏感的事实在生成当天重新核实；不确定信息必须在稿中明说不确定，不得用肯定语气编造。

## 2. 制作标准（生成时）
0. 分段制作：长音频按主题拆成若干小段分别生成，每段单独通过质检后才可拼接；整集拼接后必须再跑一遍完整质检。单段失败只重做该段，禁止用整集重生成掩盖局部失败、也禁止把失败段落拼进成品。
1. 同一系列固定主持人姓名与声音对应关系，不得中途换声。
2. 生成参数（声音、系列标识、标题、简介）必须与质检记录一同留存，可追溯到稿件文件。
3. 生成失败或单块异常时，用同一组声音重新生成，不得用换声掩盖失败；连续失败按 5 分钟、10 分钟、30 分钟、1 小时退避重试，仍失败则停止并如实告知。
4. 一集只交付一个完整文件；不得交付残缺、拼接痕迹未检或未经质检的中间文件。

## 3. 质检标准（生成后，交付前）— 四道门禁，全部通过才可交付

### 门禁 A：文件与波形
- 文件可解码、时长与稿件字数匹配（中文约每分钟 350-450 字为参考区间，明显偏离需解释）。
- 无超过 1.5 秒的异常静音（正常停顿除外）；无削波（峰值长期顶格）。
- 周期性卡壳检测：每 5 秒窗口做包络自相关，分数 >0.55 判定为卡壳/循环，整集不得有任一窗口超标；0.45-0.55 为警告，必须转写复核该段。
- 波形重复检测：任意两个相距 3 秒以上的 1 秒片段波形相关 >0.85，判定为原样重复，必须修复。

### 门禁 B：转写完整核对
- 用语音识别把整集转写为带时间戳文本，逐段对照稿子；
- 稿子的每一轮都应在转写中找到对应内容：逐轮做字词对齐，单轮对齐覆盖低于 30% 判定为该句丢失/乱码，不合格；30%-50% 必须人工定点复核。整集覆盖明显偏低需逐项解释；
- 转写中出现稿子里没有的成句内容，视为幻觉/乱码，必须定位时间点并修复；
- 识别置信度异常低的片段必须标记并结合波形复核，不得直接放行。

### 门禁 C：重复与乱码
- 重复：转写中长度不少于 8 个字的短语，在 120 秒内出现 2 次以上、且稿中没有同样重复的，判定为重复语音，不合格；
- 同一段转写文本与另一段相似度 >0.8 且不在稿中对应不同轮次的，判定为疑似重复，必须人工复核时间点；
- 乱码：转写出现无意义音节串、与上下文无关的外来语句、同一词语无意义连复读，均判定不合格；
- 注意区分识别误差（如专有名词被误听）与音频本身乱码：以是否能在转写中重复出现、是否与稿子对应来判断，并在报告中注明。

### 门禁 D：语义与表达
- 逐段读转写，确认每句意思完整、指代清楚、术语前后一致、数字和名称与稿子一致；
- 发现歧义句式（多重否定、指代链断裂、条件与结果不匹配）在音频层面无法修正时，退回改稿并重新生成；
- 开头必须交代本集问题，中段每部分有明确主题句，结尾有可复述的要点；听众只听声音即可理解，不得出现“如图所示”等视觉依赖表达。

## 4. 交付门禁与记录
1. 四道门禁全部通过，才可把音频发给用户；任一不合格，修复或重新生成后从门禁 A 重新跑完整质检，不得只复检修复点。
2. 每集留存一份质检报告（机器可读结果 + 人读结论），包含：稿件版本、时长、波形结果、转写覆盖与重复清单、语义复核结论、是否通过。
3. 交付时如实告知已核验范围；出现用户指出的新问题，立即把该类问题加入质检清单，并回溯检查同一系列已交付集数。
4. 用户反馈的问题优先级最高：用户指出的时间点必须在报告中被定点复核并给出明确结论（确认/未复现及证据）。
