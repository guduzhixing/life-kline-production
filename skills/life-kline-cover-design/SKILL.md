# 人生K线 · 封面设计（Life K-Line Cover Design）

把 33 支已拍板封面的经验固化成流程：**封面 = 公有领域真迹底图 + 程序化二创层（读真实价格的金线 + 一层克制专属层 + 衬线标题锁版）**。底图内容零篡改，只许裁切、常规明暗与叠加层。本 skill 只管封面；生产流水线、音频门禁、渲染纪律以 `life-kline-production` skill 为准。

核心信条三条：

1. **先两式、后拍板**：每支必出 A/B 两式设计稿（1080×1920 定稿级 + 320 缩略），用户拍板后才集成定版；选定结果必须回写本支 `out/coverdesign-<id>/SOURCES.md`「选定」节。
2. **金线只读真数据**：封面金线一律读 `data/figures/<id>.json` 的 segments 价格链（priceFrom + 逐段 priceTo），峰/谷金点落在真实极值上，禁止手绘示意线充数（杜甫早期稿的「构图示意」口径已废）。
3. **查重先于选图**：候选底图的对象号必须先过全系列对象号全集 grep（见 §5），撞图是本系列真实发生过的事故（见 §8），不是理论风险。

## 1. 两式定义与版式参数规格

画布统一 **1080×1920**，另出 **320×569 缩略图**做可读性自检。字体 Noto Serif CJK Bold（`NotoSerifCJK-Bold.ttc`，index=2）。色板（后期定稿标准，PIL 实测口径）：

| 角色 | 值 |
|---|---|
| 纸色 PAPER | (244, 238, 226) |
| 墨 INK | (38, 34, 30) |
| 弱化 MUTED | (110, 100, 88) |
| 红 RED | (192, 44, 38) |
| 金芯 GOLD_CORE | (197, 150, 58) |
| 金亮 GOLD_LIGHT | (255, 214, 110) |
| 金点 GOLD_DOT | (232, 176, 75) |

文字锁版四行（两式同字号）：标题 **118px**（字距 2）、钩子行 **56px**、极值行 **51px**（字距 3）、署名行 **45px**（MUTED 色）。

### A 式 · 全幅沉浸

- 底图画心 9:16 竖裁全幅铺底（下采样为原则，放大须申报，见 §5）。
- 暖金径向辉光一层（锚在主体/峰值点附近，如月轮、孤舟、人物组身后）。
- 纸色带 veil：y 1060–1600，峰值 alpha 0.88、羽化 90（逐行渐变带，非硬边矩形）。
- 金线带：x 90–990、**y 300–700**（按本支价格链 min/max 归一）。
- 标题锁版 text_block **cy=1240**：标题 cy−145、钩子 cy+5、极值 cy+103、署名 cy+186。
- 适用：底图本身有强主体/强意象（月、海、鹤、舟、莲、瀑），竖裁后主体完整、留白能承金线与纸带。

### B 式 · 分幅稳重

- 纸色整幅打底；底图入上部窗格 **940×1190**、贴于 (70, 64)；双线窗框（金芯宽 4 的内框 (70,64)–(1010,1254) + 墨线宽 2 的外框外扩 12px）。源图长宽比不合时窗高可缩至 856（如李斯/司马迁/李煜 B），金线带随之调整。
- 金线走**低位带 y 1290–1440**、x 110–970（短窗变体约 y 990–1150）。
- 标题区下移：标题 cy=1560、钩子 1696、极值 1786、署名 1858。
- 适用：底图是人物场景/叙事场景（授经、展卷、猎手），全幅竖裁会切碎人物；或横幅/手卷只能取一段入窗；或人物气质收束沉静、全幅大景反而不贴。

### 金线层画法（两式共通，代码口径）

- 数据：`vals = [segments[0].priceFrom] + [s.priceTo for s in segments]`，x 等距、y 按 min/max 线性映射到金线带。
- Catmull-Rom 平滑（每段 14 采样）；2 倍超采样绘制后缩回：辉光描边宽 15·S、alpha 46 → 主线宽 5.5·S、alpha 216 → 高光线宽 2·S、alpha 88；高斯模糊 0.5。
- 峰/谷金点四层同心圆（半径 30/16/11/4.5，alpha 52/140/255/235），峰点、谷点各一。
- 归一区间口径必须与钩子卡一致并写进 SOURCES（如杨万里支归一 12–38 为生前口径，身后 40 不入金线）。

**数据结论（33 支已拍板）：**

- **A 胜 24 支、B 胜 9 支**。两式成型期（第 3–33 期）A 23 : B 8，A 胜率约 **74%**——默认把强式做在 A 上，A 是主推位。
- **B 的胜场从来不是「分幅版式」本身赢的，是母题赢的**：早期 B 胜场（陶渊明桃花源、王安石市井、王维秋山、孟浩然渔隐）其实都是全幅变体，只是稿签为 B；分幅窗格成型后（18 期起）的 4 次 B 胜（杜牧、李斯、司马迁、孟子）有共同点——**B 的母题是「本事」而 A 的母题只是「氛围」**：伏生授经=史家本业（SOURCES 原话「与人物本业贴合度最高的一式」）、松崖展卷=讲学著述、上蔡东门=临终典故的动作场景、山行秋山=课本锚点《山行》的标题图本身。
- **A 的胜场母题是强符号单景**：月（李煜/秦观/白居易）、鹤（刘禹锡）、怒海（曹操）、孤舟（文天祥/庄子）、莲（杨万里）、雅集正座（荀子）。诗人/词人支尤其如此——一首名篇的一个意象压满全幅就是最优解。
- **人物型与胜式相关**：史家/思想家/著述型（司马迁、孟子）与「结局意象强于巅峰意象」型（李斯）是 B 的主要胜场人群；选图时这类人物要认真把 B 做成「本事场景」，不要拿氛围图陪跑。
- **清晰度是硬门槛**：需放大成图的候选系统性吃亏——王维 A（辋川手卷段约 2.08× 放大）落选、陶渊明 A（原图宽 518px）备选注记即预警；下采样成图是 A 胜场的普遍条件。放大 >约 1.15× 必须在 SOURCES 如实登记并预期减分（李煜 A 1.14× 申报后胜出是上限附近的例外，靠母题强度扳回）。
- **日本画家底图口径在收紧**：早期日本作品两胜（范仲淹 A 狩野派岳阳楼、欧阳修 A 田能村竹田），但秦观支起弃选记录已把「日本画家」列为明确减分项（連弃三件）。新支默认优先中国画；用日本作品须在 SOURCES 说明理由并预期用户知情。
- **装裱与题字是减分项**：装裱残边（王维 B 右缘 15px 登记）、题字密布（秦观弃 49153）、扇面几何不合矩形画窗（李商隐弃扇面三件）——出稿前先处理或弃选，别把问题留给用户挑。

## 4. 文案规格（钩子行 / 极值行 / 署名行）

- 标题行：`{姓名}的人生K线`，全系列同格，不加副题。
- 钩子行句式：`一根K线，看完他<红字短语>的一生`（变体可换尾，如杨万里「…哭尽一生的故事」）。红字只点**一个**短语（2–5 字：才高运蹇/碑倒又复立/北伐/写鬼写狐/一步之遥等），是全行唯一的红色语义锚。
- **钩子行字形数上限 20**（56px 字号单行容纳极限）：孟子支首渲 21 字形折行两行、把署名行挤出画外——超限先删标点/压缩短语成单行（定版口径「一根K线，看完他生前碰壁身后封神的一生」，去句中顿号），不许靠缩小字号硬塞。
- 极值行：`最高 {H} · 最低 {L}`，数字与片头钩子卡、figure 数据**同口径同值**；身后定格价是否入卡逐支在 SOURCES/骨架里写明分账（两先例并存：魏征 46、文天祥 42 为身后定格入卡；孟子 48、秦观 44、杨万里 40 仅 finale 口播不入卡——按本支骨架既定口径执行，不临场改）。
- 署名行：`{朝代} · {姓名} {生年}—{卒年}`（如「唐 · 魏征 580—643」「南宋 · 杨万里 1127—1206」）。朝代写错是真实事故（韩愈支初版误写「宋」已更正）——出稿前逐字核。
- 片尾主行字形数上限 **12**：孟子支「民为贵，社稷次之，君为轻」13 字形超宽溢出，定版缩题「民为贵，君为轻」（全句仍留在 finale 诗句行与口播中）——缩题只缩卡面，内容不许删。

## 5. 选图协议（核权 / 查重 / 可行性）

### 5.1 来源与核权

- 底图只用**公有领域/CC0**藏品：Met Open Access 为主通道，克利夫兰 CC0、普林斯顿 IIIF、Wikimedia Commons CC0、纳尔逊-阿特金斯为辅。
- 每件候选必须经 **objects 端点逐件核 `isPublicDomain = true`** 并在 SOURCES 记录对象号、原图直链、本地存档路径；接口曾出现同 ID 两次返回不同标题的串扰（李清照支），须「两次拉取一致 + 下载原图目视核对」双确认。
- Met `/search` 端点已于 2026-10-01 下线（410）。现行通道三选一：① v1.1 检索端点；② Open Access 全量 CSV（MetObjects.csv）流式过滤（Department + Paintings + PD + 题名关键词）再 objects 端点逐件核；③ web 检索定位对象号 → objects 端点核。扫描脚本与日志存本支 coverdesign 目录备查；扫描 stdout 曾出现对象号-题名配对失真（魏征支首轮），候选一律以 objects 端点直查记录为准。
- 取图优先主图高清原图；主图构图不合时可用 additionalImages 细节图（荀子 A 用分段图取正座组、庄子 A 用竖幅细节图），在 SOURCES 注明。

### 5.2 全系列查重（出稿前必做，留痕）

```bash
# 汇已用/已备选对象号全集（定版 + 在制 + 弃选都在内）
grep -rhoE '\b[0-9]{5,6}\b' out/coverfinal-*/COPYRIGHT.md out/coverdesign-*/SOURCES.md | sort -u
```

- 候选对象号（含本支备选）**不得出现在全集内**；已用规模参考：24 期时 62 个、32 期时 86 个、31 期时 90+ 个，只增不减。
- **近号逐字核**：对象号与原图文件名相近不是同一件（王维支 DP165348_CRD.jpg 与 DP165839_CRD.jpg 并存），比对须逐字，不许凭眼熟放行。
- **母题级查重**（对象号不重也要查）：同母题邻支相撞同样弃——苏洵支备选《松下高士图》因画中白鹤与刘禹锡定版「秋词一鹤」母题相邻弃用；庄子 B 候选 41146 是柳宗元定版图直接排除；一切兰亭题材避让王羲之支预留（Met 51800），预留号视同已用。
- 查重结论（检索范围、已用计数、候选不在集内）写进本支 SOURCES「全系列查重」节。

### 5.3 分辨率与竖裁可行性

- 成图必须以**下采样**为主：裁切窗原生像素 ≥ 成图尺寸（A 全幅 1080×1920；B 窗格 940×1190 或 940×856）。放大倍率逐支算清写进 SOURCES；>1.15× 申报并预期减分（见 §2）。
- 画种取景：立轴最顺（画心行带先实测检出再裁，避装裱与题跋主体）；手卷取一段（先扫全卷定段）；团扇/册页取内接竖幅（柳塘、月下波浪先例）；横幅/方形油画用分数框裁（曹操 Homer 方画裁 (0.235,0)–(0.7975,1)）；扇面几何与矩形画窗不合者原则上弃。
- 裁切避让：题跋区原则上裁出画面（保留时须确认不与金线/纸带交叠——杜牧 A 题跋区与金线交叠被判「可接受」是下限案例，不作范例）；装裱边裁净（欧阳修支收紧裁框消除绿边/浅边；残留如王维 B 右缘 15px 须登记）。
- 320px 自检：两式各出 `_320` 缩略，标题/钩子/极值/署名四行可读、主体与金线峰谷点可辨，才有资格呈给用户。

## 6. 定版集成（coverfinal）

用户拍板 + 音频确认门禁通过后执行，产物落 `out/coverfinal-<id>/`：

- 文件：`make_cover_final_<id>.py`（从设计脚本**原样抽取**选定式的布局函数，不重写参数）、`cover_<id>_final.jpg` + `_320.jpg`、`COPYRIGHT.md`（底图授权逐项）、`LAYERS.md`（图层表）、`cover_spec.json`。
- 图层结构：L0 底图层（底图+辉光+纸色带烤入 base）→ L1 金线独立透明层 `kline_gold_<id>.png`（引擎 draw 动画约 2.2s 绘入；峰/谷金点像素坐标换算归一值写入 cover_spec 并注入 `figure.meta.cover.layers[0].dots`，引擎金点与静态定稿必须同位）→ L2 专属层（见下）→ 文字由引擎 CoverLayer 按 `textCenterFrac` 绘制。
- **专属层只许一层、必须克制**，且须呼应锚点意象。已用谱系：月晕/月光波纹（白居易/李煜/刘禹锡）、瀑布水雾（李白）、赤壁火星（杜牧）、落红花瓣（龚自珍）、柳丝水纹（蒲松龄）、夜读灯晕（苏洵）、烛光（蒲松龄 B 稿）、海雾浪沫（曹操/文天祥）、排云云气（刘禹锡）。新支专属层不许与邻支同物。
- 静态定稿与设计稿一致性验证：JPEG 对 JPEG 全幅比对，差异像素（阈值 >20）须为 0（孟子支定版先例）；不一致先查参数漂移，不许将就。
- 第 0 帧纪律（与生产 skill 同步）：片头第一帧即完整成幅（底图+标题+关键元素齐全），金线作增强层随后绘入，不许黑场淡入。
- `textCenterFrac` 是逐支参数（李煜 0.646、孟子 0.852），集成后必须抽帧实测署名行在位（见 §7），不许套用他支数值盲渲。

## 7. 溢出前置检查清单（母版渲染前，全过才开渲）

孟子支首渲因卡片文字溢出整渲作废两轮（钩子折行挤出署名行 + 片尾主行超宽），龚自珍支首渲诗句行溢出、蒲松龄支 finale 红签重叠——以下检查一律在 **360 审片或静态帧**阶段做完，不许把问题带进 1080 母版：

- [ ] 第 0 帧：钩子行单行完整、未折行；署名行在画内、四行间距正常。
- [ ] 钩子行字形数 ≤20、片尾主行字形数 ≤12（§4），超限已按缩题/删标点口径处理并回写骨架。
- [ ] `textCenterFrac` 本支实测值已定，抽帧确认标题块整体不越界（不套他支数）。
- [ ] finale 诗句行不溢出画宽；红签（tags）互不重叠、与诗句行不打架（蒲松龄支「病→摊」先例：同段红签错开 atSec 或改字）。
- [ ] 典故卡长文案在卡宽内（引擎字号固定，长句先在数据层断行/缩写）。
- [ ] 金线峰/谷金点与静态定稿同位；地图红点、印章帧各抽一帧在位。
- [ ] 320 缩略复检定版静态图：四行文字可读（出设计稿时查过，集成后必须再查一次）。

## 8. 事故与教训（每条都有出处，违反即重蹈）

1. **撞图事故（孟浩然支）**：原选 B 底图 Met 853796 叶光《渔翁观月图》已是白居易支定版封面，靠出稿前 grep 全系列 COPYRIGHT/SOURCES 才拦下，改选 49019。此后查重列为出稿前置动作（§5.2），且查重范围含在制支与弃选登记，不只定版。
2. **文字溢出整渲作废（孟子支）**：钩子 21 字形折行挤出署名行、片尾 13 字形主行超宽，首渲二渲母版全废；修法是文字侧解决（去顿号单行化、缩题）+ `textCenterFrac` 0.881→0.852，三渲才成。此后立 §7 前置检查，版式问题必须在 360/静态帧阶段清零。
3. **金线示意线废止（杜甫支早期稿）**：设计稿阶段曾用「构图示意」金线，与片中真实走势脱钩；现行口径金线只读 figure 真实价格链，设计稿与定版同数。
4. **接口串扰与端点下线**：Met search 410 下线、objects 串扰、扫描 stdout 失真都发生过——核权只认 objects 端点直查 + 原图目视（§5.1），不认搜索结果页转述。
5. **朝代写错（韩愈支）**：设计稿初版署名行误写「宋」，自检发现更正。署名行出稿前逐字核（§4）。

## 9. 流程速查（单支封面全程）

1. 读本支骨架：锚点篇目、价格链、钩子卡极值口径先定（§4 分账写明）。
2. 按意象映射（§3）定两式母题（不同场景/不同句），按选图协议（§5）找图、核权、查重、算放大倍率。
3. 按 §1 参数出两式设计稿 + 320 缩略自检；SOURCES.md 写全（出处/裁切/二创层/弃选理由/查重结论）。
4. 两式呈用户拍板（全图 + 缩略图）；选定回写 SOURCES「选定」节。
5. 音频确认后按 §6 集成 coverfinal；§7 清单全过 → 母版渲染（串行纪律见生产 skill）。
6. 定版后 coverfinal 静态 JPG 另备平台上传；本支对象号自然进入下一支的查重全集。
