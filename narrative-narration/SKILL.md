# 解说叙事 · Narrative Narration（短视频解说文案方法论）

为短视频/数据可视化视频生成**可直接配音**的解说文案。核心信条：文案不是 AI 随手写的作文，而是按成熟解说工业的方法论，绑定既定分镜与时间戳、逐段交付的工程件。

## 来源与许可（方法论出处，非原创）
- **NarratoAI**（github.com/linyqh/NarratoAI，MIT）：纪录片解说文案生成提示词 v2.0（viccy同学）——黄金三秒、十大钩子、15–20 字短句、信息密度、留白、绑定规则。原文存档于本目录 `narratoai_narration_generation.py.txt`。
- **OpenMontage**（github.com/calesthio/OpenMontage，AGPL-3.0）：`skills/creative/storytelling.md`（But-Therefore 连接法、解说弧线、节奏与静默规则）与 `skills/meta/voice-performance-director.md`（配音表演契约、样本门禁）——此处仅以自有文字转述其原则，不复制原文。
- 本 skill 的「人生K线领域层」为本项目自创补充。

## 工作流（五步，缺一不可）
1. **锁定上游**：分镜表/段时间戳/画面元素必须先行确定。文案只能绑定它，**不得改动段落、时间戳，不得虚构画面里没有的内容**（NarratoAI 绑定规则）。
2. **选钩子**：开头 3 秒必须用钩子（悬念/反转/数字冲击/痛点/惊叹/疑问/对比/秘密/共鸣/颠覆认知 十选一），并在文案头部注明用了哪一类。
3. **逐段成文**：按段落逐段写，每段输出结构化字段（见输出契约）。段间连接词只许用「但 / 可是 / 然而 / 因此 / 于是」类转折推进（But-Therefore 法），**禁止「然后……然后……」流水账**（解说推进句可少量用“然后”作段内转折，全篇不超过 2 次）。
4. **表演标注**：每段必须带 delivery_cues（语速档、能量、重音词、段前/段后停顿秒数、一句具体的表演指示）。禁止只写“自然一点/有感情”这类空话。
5. **样本门禁**（配音阶段）：先合成**表演最敏感的一段**（不是第一段）试听定版，音色/语速/参数冻结后才批量生成；换音色必须重过门禁。

## 硬规则
- **单句 12–22 字**，口语，像跟朋友讲故事；不用书面长句、不用术语堆砌。
- **信息密度**：每 5–10 秒一个新信息点；总字数预算 = 总时长 × 语速档（慢 3.9 / 常 4.4 / 快 4.9 字每秒），逐段核算，超预算先砍修饰、再砍次要信息，**典故优先保留**。
- **情绪曲线**：先扬后抑或先抑后扬必须成弧线；关键揭示后留 1–3 秒静默（留白），视觉高潮处文案精简、让画面说话。
- **史实纪律**：涉及历史人物时，每个典故/引文必须可查证并在脚本附注中标明出处（如《宋史·苏轼传》《自题金山画像》）；拿不准的典故宁可不用，禁止编造“据说”式野史当史实讲（民间传说要用必须显式标为传说）。
- **读音预检**：成稿时同步产出「读音风险表」：生僻字、人名、地名逐个注拼音，并给出 TTS 输入替字方案（同音常用字替换，仅用于合成输入，不改文案正字）。

## 人生K线领域层（本系列专用）
- **转折点必落典故**：每个价格转折段（涨停/跌停/停牌/退市/反弹）至少绑定一个具体典故或一件具体小事（一个人、一句话、一道菜、一首词），禁止整段只有行情播报。
- **双线咬合**：每段文案 = 行情句（与大字卡呼应）+ 故事句（典故）各至少一句；故事句在后，情绪落在故事上。
- **收尾回扣**：结尾段必须回扣开头钩子或人物自述原话（如本人诗句），形成闭环；引文保持简短并注出处。
- **同步容差**：解说段与画面段允许 ±1.5 秒错位，超出必须调整段界或删减；静默留白优先放在丧亲、最低点、收束三处。

## 输出契约（每支脚本交付为一份文档，含五部分）
1. 头部：所用钩子类型、全片情绪曲线一句话、voice_performance 总纲（表演意图/语速曲线/停顿政策）。
2. 逐段表：段号 | 时间窗 | 对应画面 | 解说词（逐句） | 字数/预算 | delivery_cues | 典故与出处。
3. 读音风险表。
4. 纯解说词清单（仅台词，供合成/录制直接取用）。
5. 自查记录：逐段字数核算、But-Therefore 检查、史实出处核对、虚构内容声明（应为零）。
